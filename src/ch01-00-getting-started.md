# Primeiros Passos

Vamos começar a sua jornada em Rust! Há muito o que aprender, mas toda jornada começa
em algum lugar. Neste capítulo, vamos discutir:

- Como instalar o Rust no Linux, macOS e Windows
- Como escrever um programa que imprime `Hello, world!`
- Como usar o `cargo`, o gerenciador de pacotes e sistema de build do Rust
