# Prefácio

A linguagem de programação Rust percorreu um longo caminho em poucos anos, desde
sua criação e incubação por uma comunidade pequena e nascente de entusiastas, até
se tornar uma das linguagens de programação mais amadas e requisitadas do
mundo. Olhando para trás, era inevitável que o poder e a promessa do Rust
chamassem a atenção e ganhassem espaço na programação de sistemas. O que não era
inevitável era o crescimento global de interesse e inovação que permeou as
comunidades de código aberto e catalisou a adoção em larga escala em todos os setores.

Neste momento, é fácil apontar para os recursos maravilhosos que o Rust
tem a oferecer para explicar essa explosão de interesse e adoção. Quem não
quer segurança de memória, *e* alto desempenho, *e* um compilador amigável, *e*
ótimas ferramentas, entre uma série de outras características fantásticas? A linguagem Rust que
você vê hoje combina anos de pesquisa em programação de sistemas com a sabedoria
prática de uma comunidade vibrante e apaixonada. Esta linguagem foi desenhada com
um propósito e construída com cuidado, oferecendo aos desenvolvedores uma ferramenta que facilita
a escrita de código seguro, rápido e confiável.

Mas o que torna o Rust verdadeiramente especial são suas raízes em capacitar você, o usuário, a
atingir seus objetivos. Esta é uma linguagem que quer que você tenha sucesso, e o
princípio de capacitação está no núcleo da comunidade que cria,
mantém e defende esta linguagem. Desde a edição anterior deste
texto definitivo, o Rust evoluiu ainda mais para se tornar uma linguagem global e confiável.
O Projeto Rust agora é solidamente apoiado pela Fundação Rust,
que também investe em iniciativas-chave para garantir que o Rust seja seguro, estável
e sustentável.

Esta edição de *A Linguagem de Programação Rust* é uma atualização abrangente,
refletindo a evolução da linguagem ao longo dos anos e fornecendo novas e valiosas
informações. Mas não é apenas um guia de sintaxe e bibliotecas — é um
convite para se juntar a uma comunidade que valoriza qualidade, desempenho e design
consciente. Seja você um desenvolvedor experiente querendo explorar o Rust pela
primeira vez ou um *Rustacean* experiente procurando aprimorar suas habilidades, esta
edição oferece algo para todos.

A jornada do Rust tem sido de colaboração, aprendizado e iteração. O
crescimento da linguagem e de seu ecossistema é um reflexo direto da comunidade vibrante e
diversificada por trás dela. As contribuições de milhares de desenvolvedores, desde
os projetistas centrais da linguagem até contribuidores eventuais, são o que tornam o Rust uma
ferramenta tão única e poderosa. Ao pegar este livro, você não está apenas aprendendo uma
nova linguagem de programação — você está se juntando a um movimento para tornar o software melhor,
mais seguro e mais agradável de se trabalhar.

Bem-vindo à comunidade Rust!

- Bec Rumbul, Diretora Executiva da Fundação Rust
